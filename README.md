# 🚀 Welcome to TGAD Community
*(The Game And Developer Community)*

We welcome open-source games made with **any game engine or programming language!**

To submit your game to TGAD, send an email to **tgadcommunity@gmail.com** with a highly compressed file (e.g., `.tar.gz`) containing your source code.

---

## 📩 Email Requirements

Your submission email **must** include:

* **Game Name**
* **Developer / Creator Name**
* **Game Engine or Programming Language Used**

---

## ⚠️ Special Rule for Unreal Engine Projects

Due to Epic Games licensing policies, public repositories containing Unreal Engine source assets cannot be visible to everyone.

* **How to submit:** Send an email to request access.
* **Verification:** Your GitHub account **must** be linked to the official Epic Games GitHub organization.
* **Review:** If linked, you will be granted access to the hidden source code viewing team. If not, your request will be **automatically rejected**.
